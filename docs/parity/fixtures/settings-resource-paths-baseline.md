# Resource path settings baseline

Reference: current Pi `main` at `6f7551516b84278eb9da1c340c8e7bc66be1a6ba` (Pi 0.87.1).

Pi defines `extensions`, `skills`, `prompts`, and `themes` as string arrays in user and project `settings.json`. User paths resolve from the agent directory; project paths resolve from `<cwd>/.pi`. Pi's package manager reads the scopes independently and adds resources from both. It processes project entries before user entries, and project resources load only for a trusted project. Ordinary entries identify local files or directories. `!pattern` filters matching resources, `+path` force-includes an exact path after glob exclusions, and `-path` force-excludes an exact path after force-inclusion. Those rules also filter each scope's automatic resource directories. Skill patterns may identify a skill by its `SKILL.md` or its containing directory.

The behavior is defined in the pinned Pi [settings documentation](https://github.com/earendil-works/pi/blob/6f7551516b84278eb9da1c340c8e7bc66be1a6ba/packages/coding-agent/docs/settings.md#L128-L141) and [`package-manager.ts`](https://github.com/earendil-works/pi/blob/6f7551516b84278eb9da1c340c8e7bc66be1a6ba/packages/coding-agent/src/core/package-manager.ts#L713-L780): `DefaultPackageManager.resolve`, `resolveLocalEntries`, `addAutoDiscoveredResources`, `applyPatterns`, `matchesAnyPattern`, and `matchesAnyExactPattern`. Upstream [`package-manager.test.ts`](https://github.com/earendil-works/pi/blob/6f7551516b84278eb9da1c340c8e7bc66be1a6ba/packages/coding-agent/test/package-manager.test.ts#L1965-L2114) covers force-including extensions, prompts, themes and skills after exclusions, then force-excluding resources after inclusion.

PiSharp now parses all four arrays, retains separate user/project values through runtime construction, and exposes an additive combined view through `UserSettings.Overlay`. Relative paths and patterns use their owning scope base. User settings apply in every project; trusted project settings load only after the existing trust decision. Resource and extension catalogs apply local paths and the `!`/`+`/`-` rules to configured and automatic candidates. Theme paths join project-before-user lookup. `/reload` rebuilds resources, extensions and the theme catalog from freshly loaded settings.
