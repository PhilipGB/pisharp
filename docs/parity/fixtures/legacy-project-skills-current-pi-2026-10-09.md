# Legacy project skills settings differential

This fixture checks Pi's deprecated object form for the `skills` setting in a trusted project's `.pi/settings.json` against current Pi `f1b2e77f5b13b2a199b1052cb79c235451afe7d7` and PiSharp source `1ff661e129f5fe654db9dde13b44e6af6149eb39`.

Pi migrates `skills.enableSkillCommands` to the root setting only when the root property is absent. A nonempty `skills.customDirectories` array replaces the legacy object with the configured project skill paths; an empty or missing array removes the legacy `skills` property. A root `enableSkillCommands` value wins regardless of property order. The migrated paths remain scoped to the trusted project's `.pi` directory. The setting disables autocomplete suggestions while keeping manually entered `/skill:name` expansion available.

The first PiSharp regression run failed before the fix: `UserSettingsTests.LegacySkillsObjectMigratesProjectDirectoriesAndSettingPrecedence` rejected the object with `settings.json skills must be an array of at most 512 paths or patterns.` The parser now migrates the legacy object, preserves the root-over-nested precedence, and resolves the path through the existing project resource rules. The focused regression passes.

The paired terminal fixture writes the legacy object and a project skill into a trusted project, types `/skill:` and confirms that no completion appears, then manually enters `/skill:legacy-project-skill <argument>`. Current Pi and PiSharp each make one provider request, expand the same skill content, preserve the argument, disable completion, and finish without a scenario error. The behavior assertion is in [behavior.json](legacy-project-skills-current-pi-2026-10-09/paired/behavior.json); the exact pins, frame comparison, request trace and compressed capture are in [report.json](legacy-project-skills-current-pi-2026-10-09/paired/report.json) and [the capture](legacy-project-skills-current-pi-2026-10-09/paired/120x40-dark-fullscreen.json.gz).

HTTP traces also differ in the projected system prompt and skill-message metadata. These visual/request differences do not change the matched legacy-settings behavior. Same-Pi calibration has zero normalized state and render differences across nine frames and an exact HTTP trace; raw terminal bytes differ.
