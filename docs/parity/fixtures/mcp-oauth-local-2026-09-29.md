# MCP OAuth local checkpoint, 2026-09-29

Reference: current Pi `5257d0d5f3ab7d42550804f32c67a77b49f485d4`, `packages/coding-agent/src/extensions/mcp/{oauth,runtime,cli}.ts`, and the official C# MCP SDK 2.2.0 OAuth and transport APIs. This is a local protocol fixture, not a paired Pi/PiSharp differential.

PiSharp now uses the SDK's OAuth discovery, PKCE, authorization-code exchange and refresh path for HTTP MCP servers without an `Authorization` header. Normal startup supplies a callback that reports explicit sign-in is needed; it never starts a browser. `pisharp mcp login <server>` listens only on loopback, prints the authorization URL and receives the `code`, `state` and optional `iss` parameters for SDK validation. `pisharp mcp logout <server>` deletes that server's cached tokens. Credentials are stored by absolute server URL in `<agent-dir>/mcp-auth.json` using an atomic, private file write and an interprocess file lock for edits. The SDK's token container includes client registration and authorization-server identity so process restart can use the same refresh credential.

`McpOAuthTests` exercise a deterministic HTTP resource/authorization-server fixture: the initial connection reports `needs-auth`, explicit login exchanges a code, the cache stores access and refresh tokens, and a fresh MCP connection uses the stored token. Separate tests cover URL isolation, private file mode, concurrent edits, scoped logout and invalid callback/header configurations. The local focused lane passed 5/5 and the sequential full suite passed 848/848 with zero skipped. Exact-head CI run [36576153201](https://github.com/PhilipGB/pisharp/actions/runs/36576153201) passed restore, format, warnings-as-errors build and 848/848 tests (zero skipped).

Remaining gaps: cross-process refresh serialization and rotated-token coordination (the SDK only locks within one process), sign-in over SSH with a pasted callback URL, upstream's broader callback settings, `/mcp` TUI status/management, lazy connection/reconnect and extension-registered servers. Token storage is a restricted local file, without OS credential-store encryption. MCP OAuth is not yet a full parity claim.
