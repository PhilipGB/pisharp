# Markdown code block indentation baseline

The reference is pinned Pi `2b0a123de98318c2ff8069661721ce0c3794c34e`. Its [`settings.md`](https://github.com/earendil-works/pi/blob/2b0a123de98318c2ff8069661721ce0c3794c34e/packages/coding-agent/docs/settings.md) defines `markdown.codeBlockIndent` as a string with a two-space default. The pinned [`interactive-mode.ts`](https://github.com/earendil-works/pi/blob/2b0a123de98318c2ff8069661721ce0c3794c34e/packages/coding-agent/src/modes/interactive/interactive-mode.ts) passes it into `MarkdownTheme`; the [`markdown.ts` renderer](https://github.com/earendil-works/pi/blob/2b0a123de98318c2ff8069661721ce0c3794c34e/packages/tui/src/components/markdown.ts) prefixes each rendered code line with that value.

PiSharp now parses `markdown.codeBlockIndent` as a string in user and trusted-project settings, defaults to two spaces, lets a project override the user value, and saves the literal prefix through `/settings`. The active terminal screen re-renders committed and partial Markdown after a setting edit or resource reload. Clearing a scope removes that override; an explicitly empty string means no additional prefix. Unsupported Markdown setting keys remain rejected.

PiSharp retains its existing `  │` code-block gutter and inserts the configured prefix between the gutter and code content. Pi's renderer has no matching gutter. The setting therefore controls the same code-content prefix while full rendered-line geometry remains a documented TUI difference. `markdown.mermaid` and a direct paired Pi/PiSharp rendered-screen differential remain open.

`UserSettingsTests.MarkdownCodeBlockIndentUsesTheDefaultAndTrustedProjectOverride` covers defaults, project precedence, explicit empty strings, malformed values and duplicate keys. `UserSettingsWriterTests.UpdatesSupportedValuesAndPreservesOtherSettingsAtomically` covers persistence/removal. `TerminalMarkdownTests.RendererUsesTheConfiguredCodeBlockIndentAsALiteralPrefix` covers the rendered value, and `TerminalScreenTests.CodeBlockIndentChangeRendersPreviouslyCommittedMarkdownAgain` verifies a live change updates existing transcript content.
