## Corrections

The existing `EditorBuffer` mutation semantics already matched pinned Pi for the
required matrix (deletion boundaries, kill accumulation order, yank-pop state,
undo grouping and selection replacement). Two product defects were confirmed and
corrected:

- Legacy terminals send Ctrl+- as byte `0x1f`. `TerminalInput` mapped all control
  bytes to `ConsoleKey.A + value - 1`, producing an undefined key, so Ctrl+- undo
  never matched outside Kitty/modifyOtherKeys profiles. `0x1f` now decodes to
  `OemMinus+Ctrl`; Ctrl+Space, Ctrl+\\ and Ctrl+] decode to their Pi keys, and
  the Alt+Ctrl forms follow.
- Pi's `CustomEditor` dispatches application actions before editor actions
  (history actions are the documented exception). PiSharp's idle router let a
  colliding editor binding win. Application actions and clipboard paste now take
  precedence over colliding editor actions; history previous/next remain above
  application shortcuts, and an active completion cycle keeps Shift+Tab as
  completion. The existing `ConfiguredSubmitBindingAndHotkeysCommandWorkThroughLinuxPty`
  test was moved off the colliding Ctrl+X / `app.message.copy` key.
- The dedicated external-editor path also carried an editor-key collision
  restriction, so a user binding such as `tui.editor.deleteWordBackward: ctrl+g`
  skipped terminal suspension and dispatched the action through the generic path.
  The restriction is removed: the external editor always runs through the
  suspend/restore path, and the colliding editor action no longer wins.

## Findings

- **CJK word segmentation (non-required).** Pinned Pi delegates word boundaries
  to `Intl.Segmenter` (ICU). For `你好世界`, Ctrl+W deletes `世界` and Alt+D
  deletes `你好`. `EditorBuffer` treats a contiguous Han run as one word. The
  required M12 contract covers grapheme clusters, combining characters and
  multiline boundaries; reproducing ICU dictionary segmentation needs an ICU
  dependency or embedded dictionary, so this remains a documented finding.
- **Terminal rendering/control differences (non-required).** See the counts
  above. They do not change editor text, cursor lifecycle, terminal restoration
  or provider input.
