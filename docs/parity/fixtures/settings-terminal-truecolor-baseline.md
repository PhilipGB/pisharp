PiSharp parses a JSON boolean or the string `"auto"` from `terminal.trueColor`. Trusted project values override user values, including explicit `"auto"`; untrusted project settings are not loaded. A boolean setting overrides automatic capability detection for built-in and custom themes. Missing or `"auto"` values use PiSharp's existing environment detection. `/settings` offers Auto detect, Enabled, and Disabled, and rebuilds the active theme catalog after a save. Startup, trusted project adoption, and resource reload construct the catalog from the effective setting.

PiSharp's existing `NO_COLOR` and `TERM=dumb` handling has a `None` color mode, while Pi's `getTerminalColorMode()` has only `truecolor` and `256color`. Automatic mode therefore retains this existing difference for those environments; an explicit `terminal.trueColor` value selects the requested Pi color mode.
